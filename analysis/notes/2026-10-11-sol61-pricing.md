# Sol 6.1 pricing

Both `gpt-6.1-sol-medium` and `gpt-6.1-sol-xhigh` use the 2026-10-11
OpenAI Flex rates: **$1 input, $0.05 cached input and $5 output per million
tokens**. The [official model page](https://developers.openai.com/api/docs/models/gpt-6.1-sol)
lists standard rates of $2/$0.10/$10, and the
[pricing documentation](https://developers.openai.com/api/docs/pricing)
specifies the 50% Flex discount. Flex follows the existing non-batch pricing
selection policy; previously evaluated profiles retain their dated rates.

All 440 generation observations have exact recovered Codex counters, bound to
their session and transcript by the compact records in
`metadata/codex-usage/20261006-204623.jsonl`. Cost is
`((input - cached) × 1 + cached × 0.05 + output × 5) / 1,000,000`, computed
per run and then averaged. Cached input is already part of input; reasoning
is already part of output and is not charged again. An unavailable cache-write
counter remains unknown, not zero.

This estimates API-rate cost, not the Codex subscription bill. Long-context
surcharges, storage, tools, regional premiums and batch discounts are not
modeled. The frozen profiles and source URLs are retained in
`analysis/src/all_models_score_vs_cost.py` and exported with the measured
token averages to `analysis/tables/4d_all_models_score_vs_cost.csv` for the website.
