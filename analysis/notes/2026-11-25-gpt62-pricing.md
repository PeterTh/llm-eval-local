# Astra and Sol 6.2 Standard pricing

Date: 2026-11-25

The 440 Codex observations use exact final native input, cache-read and output
counters, reconciled against 11,220 request records. Cached input is a subset of
input; reasoning is a subset of output. Neither is counted twice. Cache writes
are zero. These are normalized API-equivalent costs, not subscription charges.

## Context and totals

The long-context threshold is 272,000 input tokens per request, not cumulative
session input. Above that threshold, the full request uses twice the input/cache
rates and 1.5 times the output rate. None of these observations crosses it:
Astra's 3,822 requests reach at most 80,803 input tokens; Sol's 7,398 reach 141,862.
