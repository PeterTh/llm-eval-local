# DeepSeek V4.1 Flash OpenCode pricing

DeepSeek V4.1 Flash High in OpenCode uses a dated API-rate estimate of about
$0.01940 per task with complete accounting. The cost comparison follows the
existing policy of selecting the cheapest live, non-batch OpenRouter endpoint
for the observed token mix. On 2026-10-24, that was Baidu FP8 at
$0.0537 input, $0.001074 cached input and $0.2148 output per million tokens.
The [pricing snapshot](../../batches/20261019-134042/replacements/20261024-isolated/generation/pricing/pricing-reference.json)
retains the candidate endpoints and the hash of the
[OpenRouter response](https://openrouter.ai/api/v1/models/deepseek/deepseek-v4.1-flash/endpoints).

217 of the 220 observations have complete native OpenCode counters. Cached
input is included in input, and reasoning is included in output. Per-task
cost is `((input - cached) × 0.0537 + cached × 0.001074 + output × 0.2148) / 1,000,000`.
Three model-terminated sessions retain exact counters only for completed
requests. Those lower bounds are not priced as complete tasks: full-task token
and cost fields remain empty, while validation, benchmark and score outcomes
remain included. The cost mean therefore covers 217 tasks, not all 220.

The [request-context evidence](../../batches/20261019-134042/replacements/20261024-isolated/generation/pricing/current-context-review.json)
covers 9,666 completed requests, including compaction. Maximum request input
is 328,759 tokens and maximum output is 50,344; reported cache writes are zero.
The selected endpoint has flat context pricing, so no context-tier split is
needed.

This estimate is not the OpenCode Go subscription bill or quota consumption.
The [Go allowance](https://opencode.ai/v2/docs/console/go/) uses separate rates
matching [DeepSeek's peak and off-peak pricing](https://api-docs.deepseek.com/quick_start/pricing/).
The comparison endpoint declares `deepseek-v4.1-flash-20260910` and FP8, whereas
the evaluated Go alias is unversioned. These are different serving
configurations, not evidence that the measured programs were generated by
that OpenRouter endpoint or an identical weight snapshot.
