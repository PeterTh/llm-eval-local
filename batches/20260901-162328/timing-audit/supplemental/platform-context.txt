Evaluate timing for the recorded target profile, not arbitrary machine configurations.
The target is Linux x86_64 LP64, CUDA 12.6.77, GCC/libstdc++ 13, C++17, sm_86.
Hybrid validation and future full hybrid benchmarking both use exactly 4 MPI ranks
on the same node and exactly one visible CUDA device per rank. The environment
initially lists CUDA_VISIBLE_DEVICES=0,1,2,3, but every rank starts the same wrapper
before executing the generated program. The wrapper selects one list entry by
OMPI_COMM_WORLD_LOCAL_RANK and replaces CUDA_VISIBLE_DEVICES with only that entry.
Consequently cudaGetDeviceCount in each generated rank sees exactly one device.
